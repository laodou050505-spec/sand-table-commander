# Tripo craft 玩法版设计 v1（肉鸽战役）

2026-11-19。给用户审的设计稿：先定方向，再分阶段做。模型等全部玩法做完再统一做（用户定），开发期间一律用现有模型占位。

---

## 0. 已经定下的规矩（11-16 起用户说过的，不再讨论）

- 关卡制肉鸽，单人打电脑；关卡要多（12 关太少）。
- 出战前选带哪些兵种，有数量上限；兵力损失带到下一关。
- 输了从本关重来，兵还在，不整轮重来；赢了但死太多也可以重打这一关。
- 过关三选一增益；要有永久成长。
- Boss = 巨型单位 + 随行部队。
- 兵法两层：总指挥（全军令）+ 小队指挥（指定哪队做事）。
- 敌人用深空风格的不同兵种，不按章节换风格；整体是西式科幻奇幻、不要中国风。
- 头显上玩法要简单：只靠看 / 按 / 捏 / 拖，能推出来的就自动；深度放在排兵布阵，不加一堆军令。
- 不出大段文字，玩中学；所有字都落在设计过的实物载体上。
- 现在这版单局对战 = 主菜单“演示”。

## 1. 一句话

你是星枪团的指挥官，带着一支会越打越少、也会越打越强的军队，穿过三个星区、打三十多场仗，最后打掉余烬矿帮的巨型熔核机甲。

---

## 2. 一轮战役的结构

- **三个星区（章）**，每章一张**分支航线图**（类似《杀戮尖塔》的地图）：每章 13～15 个节点，走一条路实际打 11～12 场，加章末 Boss。整轮约 35～40 场。
- 一场仗 2～4 分钟，一章 40～60 分钟，整轮 2.5～3.5 小时，分多次玩（每个节点前自动存档）。
- **节点类型**：

| 节点 | 内容 |
|---|---|
| 战斗 | 普通战，打赢给三选一 |
| 精英 | 敌人更强、带一个“词缀”，奖励更好（保底一个纹章） |
| 补给站 | 花星晶：招募新兵、治疗伤兵、兵种晋升 |
| 遗迹 | 一个两难选择（例：“献出 5 名骑兵，换一面纹章”），用图示表达，不写长文 |
| 军械库 | 直接挑一面纹章或一个指挥技 |
| Boss | 章末，巨型单位 + 随行部队 |

- **航线图怎么呈现**：沙盘本身变成星图——深空风格的立体地形，节点是立在图上的小信标，发光航线连着；手指点下一个要去的节点，沙盘“推近”过去展开成战场。不另做浮空面板。

---

## 3. 一场仗前后

### 3.1 出战前：选兵

- 你的全部兵力按兵种列在沙盘近侧的“营帐托盘”里：每个兵种一个小雕像 + 人数刻度。
- **统率上限**：初始 30 人，靠成长升到约 60 人（双方合计多少人流畅要上机实测，现在演示版是双方各 40 多人）。
- 默认按上一场的配置自动填好，玩家只需微调：手指点雕像旁的加 / 减，统率灯满了就加不上。
- 选完进入现在的布阵（拖旗牌摆位置、预定攻击目标），再按“开战”。

### 3.2 战斗中

两层指挥，见第 5 节。

### 3.3 战后

- **伤亡结算**：倒下的兵分成“阵亡”（永久失去）和“伤兵”（下一场不能上，再打一场或到补给站治疗后归队）。打赢时伤兵比例高、打输时低——赢得漂亮能救回更多人，这是“死太多要不要重打”的判断依据。溃逃的兵自动归队。
- **星级**：按存活比例给 1～3 颗星，影响星晶多少。
- **三选一**：三张拼贴风格的奖励卡立在沙盘前沿，手指点一张。
- **重打**：结算板上一个“重打这一仗”按钮，回到这场仗开打前（含选兵），兵力原样恢复，不限次数；输了直接就是这个选项。

## 4. 成长

### 4.1 一轮战役之内（这一轮结束就清零）

| 类型 | 例子 |
|---|---|
| 补员 | 某兵种 +6 人 |
| 新兵种 | 解锁一个兵种进营帐，并给 4 人 |
| 兵种晋升 | 某兵种整体升一阶：更厚的甲、更多血、换更好的武器（用现有武器数据） |
| 纹章（被动，全军生效） | “破阵”：骑兵冲锋伤害 +30%；“盾墙”：步兵坚守时正面受伤 −25%；“老兵”：伤兵比例 +20%；“急行”：开战前 10 秒全军移速 +25% |
| 指挥技（指挥台多一个按钮，每场限次） | “轨道炮击”：手指点沙盘上一处，延迟 2 秒落下范围伤害；“集结号”：全军士气回满；“烟幕”：一片区域里弓手射不准 |
| 星晶 | 补给站花 |

### 4.2 永久成长（跨轮保留）

- 每轮结束（通关或撤退）按走了多远得“荣誉”，在主菜单的“战争学院”里解锁：
  - 更多兵种进入招募池；
  - 更多纹章、指挥技进入奖励池；
  - 开局多一个兵种 / 统率上限略加；
  - 难度阶（通关后开放更难的“战役难度 1～10”）。
- 原则：**永久成长主要是“解锁多样性”，数值加成很小**，避免变成“刷”。

---

## 5. 两层兵法

- **总指挥**：指挥台上的按钮 = 全军令（冲锋 / 坚守 / 撤退），加上成长得到的指挥技按钮（最多 2 个）。
- **小队指挥**：按兵种分队（最多 6 队，选兵时自动分好），每队头顶有旗牌。
  - 拖旗牌 = 这队移动 / 进攻某支敌军（现在就有）；
  - **新增：捏住旗牌不动 0.4 秒**，旗牌下展开三枚小令（冲锋 / 坚守 / 撤退），手往那一枚滑过去松手 = 只给这一队下令。不需要先“选中”（之前点选总误触，已经去掉了），沿用现有的防误触规则。
- 敌方也是两层：敌军统帅给各编组下令，统帅有“性格”（冒进、稳守、包抄），用现有 AI 的参数做出来。

## 6. 敌人（深空风格：余烬矿帮）

在现有 9 个兵种的基础上，按章节逐步加入**规则不同**的新兵种（不只是数值更高）：

| 敌种 | 玩家要怎么应对 |
|---|---|
| 盾墙重甲 | 正面几乎打不动，要绕侧或用重击兵 |
| 爆破兵 | 冲进人群自爆，要用弓手提前打掉或散开 |
| 迫击炮组 | 远程范围伤害、很慢，要派骑兵绕过去 |
| 鼓舞旗手 | 周围敌人不崩溃，先斩旗手 |
| 骚扰轻骑 | 快、专打后排弓手，要留步兵护后 |
| 精英重甲小队 | 人少但极硬，耗时间 |

**Boss（每章一个）**：巨型单位（体型 4～6 倍、血量约一整队、范围踩击 / 横扫、血量过半召唤增援）+ 随行部队。

1. 第一章：熔炉巨像
2. 第二章：钻地攻城机（会从地下钻出、换位置）
3. 第三章：矿帮之王·熔核泰坦（三阶段）

## 7. 关卡多样性

- **地形**：沙盘地形按“种子 + 主题”生成（熔岩河、陨坑群、峡谷、平原）。模拟对地形微差很敏感，所以每张生成的地图都先用自动对战跑一批，筛掉一边倒的。
- **胜利条件**：
  - 击溃全军（默认）；
  - 坚守：守住信标 90 秒；
  - 斩首：击倒敌将；
  - 伏击：开局敌人从两翼出现。
- **精英词缀**：敌人全员加甲、援军分三批到达、夜战（远处看不清）等。

---

## 8. 难度怎么调

- 用已有的自动对战（`Editor/BalanceTest`）：每种关卡模板用一支“标准玩家军队”跑 20 局以上，量胜率和存活率。
- 目标曲线（针对中等玩家）：第一章胜率约 85%，第二章约 70%，第三章约 55%；Boss 战首次胜率 40～50%。
- 敌军人数和兵种组合按这个曲线自动生成，不手写每一关。

---

## 9. 界面（沿用现有拼贴 + 西式奇幻语言）

- 航线图：沙盘变星图（见第 2 节）。
- 营帐托盘：沙盘近侧，兵种小雕像 + 人数刻度 + 统率灯。
- 奖励三选一：三张拼贴卡片立在沙盘前沿，手指点选；卡片上用图标 + 两三个字说明，不写段落。
- 军簿：指挥台侧边一块小牌，显示总兵力、伤兵、星晶、已有纹章（图标）。

---

## 10. 和现有内容的关系

- 主菜单：“出征” = 战役（继续 / 新战役）；“演示” = 现在的单局对战（五种风格任选、自由对战）。
- 风格：战役固定深空风格；五种风格保留在演示里。
- 存档：每个节点前自动存一份；重打用“这场仗开打前”的那份；随时退出，下次从当前节点继续。
- 模型：新敌种、Boss、星图元素先用现有模型换色 / 缩放 / 拼简单部件占位，全部玩法做完再统一建模。

---

## 11. 分阶段做（每个阶段结束都能装机试玩）

1. **骨架**（最先做，验证核心循环好不好玩）：线性 8 关 + 出战选兵 + 伤亡继承（阵亡 / 伤兵）+ 重打 + 战后三选一（补员 / 新兵种 / 纹章三类）+ 存档 + 主菜单入口。
2. **地图与深度**：分支航线图和各类节点、小队令（捏住旗牌展开）、指挥技按钮、3 种新敌种、第一个 Boss。
3. **规模**：三个星区约 35～40 关、全部敌种和三个 Boss、坚守 / 斩首 / 伏击关、永久成长（战争学院）和难度阶。
4. **平衡与打磨**：自动对战调难度曲线、玩中学的提示、音乐音效。
5. 之后：统一建模（新敌种、Boss、星图）。

## 12. 用户的决定（11-19）

- 战役结构：**分支航线图**，而且要做得精致，“就像那些军事地图”（作战地图：等高线、坐标网格、军标符号、进攻箭头、手写标注）。
- 小队令：先按“捏住旗牌 0.4 秒展开三枚小令”做，有问题再调。
- 其余按推荐：永久成长以解锁多样性为主、数值加成很小；“一次就过”给一点额外星晶（我定的，鼓励但不强迫）。
- “先做出来看效果”→ 第 1 阶段直接用一章分支航线图（代替线性 8 关）。

## 13. 原来的问题（已定）

1. 战役结构：分支航线图（推荐）还是线性关卡列表？
2. 小队令：捏住旗牌 0.4 秒展开三枚小令（推荐）、把指挥台按钮拖到旗牌上、还是先不做小队令（只保留拖旗牌）？
3. 重打完全免费不限次（按之前说的）——要不要给“这一仗一次就过”额外奖励，鼓励不重打？
4. 永久成长：只解锁多样性、数值加成很小（推荐），还是也要明显的数值成长？
